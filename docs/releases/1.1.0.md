# LayoutPilot 1.1.0

## Highlights

- Added custom responsive presets to save, reuse, rename, and remove preview sizes.
- Added responsive preview capture to export the current preview as a PNG image.
- Added a pan tool to move the responsive preview in manual zoom mode.
- Responsive preview navigation now syncs with the browser URL.
- Improved the global popup layout for a cleaner and faster workflow.
- Reorganized the responsive side panel with clearer Preset, Size, Zoom, and Preview sections.
- Improved responsive preview support for pages that block iframe rendering.

## New Features

- Added a viewport pan tool for responsive preview.
  - Available in manual zoom mode.
  - Supports a hand tool button.
  - Supports holding Space to move the preview.
  - Uses an iframe overlay to allow smooth dragging.
  - Shows proper grab and grabbing cursor feedback.

- Added navigation sync between the responsive preview and the browser URL.
  - When the user navigates inside the responsive preview, the browser URL is updated.
  - Exiting responsive mode keeps the user on the navigated page.

- Added custom responsive presets.
  - Save the current preview size as a named custom preset.
  - Reuse saved sizes from their own Preset group.
  - Rename or remove saved custom presets from the responsive side panel.
  - Prevent duplicate preset names and sizes during save.

- Added responsive preview capture.
  - Captures the current preview area without including the side panel.
  - Works from the Preview section.
  - Exports a PNG image with a filename that includes the preset, viewport size, and timestamp.

## Improvements

- Simplified the global popup layout.
  - Removed redundant status information.
  - Made the mode selector more compact.
  - Simplified the responsive view block.
  - Shortcuts are collapsed by default.

- Reorganized the responsive side panel.
  - Renamed Device to Preset.
  - Added a Size section for width and height controls.
  - Added a Preview section for preview-related actions.
  - Removed the redundant Current footer from the expanded panel.

- Updated the Preview section to show only actions that apply to the current zoom mode.

- Improved Fit to screen behavior by removing unnecessary scroll and keeping the preview properly centered.

## Fixes

- Fixed responsive previews on pages that block iframe rendering through X-Frame-Options or CSP.
- Fixed inspector alignment detection for centered elements with different heights.
- Fixed popup behavior so it closes automatically after enabling responsive view.

## Notes

This release focuses on improving the responsive preview experience, making the popup cleaner, and making the responsive side panel easier to understand and use.

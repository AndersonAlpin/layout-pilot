# LayoutPilot 1.1.0

## Highlights

- Added Responsive Preview, a new workflow for testing pages across different viewport sizes without resizing the browser window.
- Improved the main popup layout for a cleaner and faster workflow.
- Fixed inspector alignment detection for centered elements with different heights.

## New Features

- Added Responsive Preview.
  - Test the current page in device, desktop, ultrawide, and custom viewport sizes.
  - Use a dedicated side panel to control preset, size, zoom, and preview actions.
  - Use Fit to screen or manual zoom depending on the review workflow.
  - Pan large previews in manual zoom mode using the hand tool or Space shortcut.
  - Save custom viewport sizes as reusable presets.
  - Rename or remove saved custom presets.
  - Capture the current preview area as a PNG image.
  - Navigate inside the preview while keeping the browser URL in sync.
  - Load supported pages inside the preview even when they normally block iframe rendering.

## Improvements

- Simplified the main popup layout.
  - Removed redundant status information.
  - Made mode selection more compact.
  - Shortcuts are collapsed by default.
  - Improved the flow for opening Responsive Preview from the popup.

## Fixes

- Fixed inspector alignment detection for centered elements with different heights.

## Notes

This release introduces Responsive Preview as a new workflow for testing layouts across different screen sizes, along with a cleaner popup and improvements to the existing inspector.
